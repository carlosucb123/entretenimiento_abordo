# Entretenimiento a bordo

¡Bienvenidos al proyecto!

## ¿De qué trata?
Desarrollaremos una aplicación de entretenimiento para pasajeros, con acceso a películas, música y juegos mediante una red Wi-Fi local.

## Tecnologías
- Flutter: interfaz de usuario.
- Python y FastAPI: servidor local.
- Firebase: sincronización de información cuando haya internet.
- GitHub: colaboración y control de versiones.
-sql-lite
## Trabajo en equipo
